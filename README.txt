WORKTRACK PROTOTYPE

This is a static prototype. It uses browser localStorage for demo data, so it is NOT yet suitable for real customer data.

TEST:
1. Open index.html.
2. Click Open Demo.
3. Open Room 204.
4. Copy the displayed public URL.
5. Open the Public Page.
6. The same public page can be used as the URL written to an NFC tag once the site is hosted.

IMPORTANT:
- This prototype does not have real accounts or secure multi-business permissions.
- Photo examples use public demo image URLs.
- The next production step is a real backend/database/authentication/storage layer.
